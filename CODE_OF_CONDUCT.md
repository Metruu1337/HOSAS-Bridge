# Community conduct

Treat people respectfully regardless of experience, identity, background or hardware budget. Critique code and behavior, not people. Harassment, threats, discriminatory language, doxxing and exposing private logs/credentials are unacceptable.

Maintainers may remove harmful content, lock discussions or restrict participation proportionately. Report privately using a maintainer-provided channel; none is configured in this local checkout. Do not repost private material to report it. Specific constructive technical disagreement is welcome.
