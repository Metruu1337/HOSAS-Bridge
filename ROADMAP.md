# Roadmap

Before 1.0: owner hardware checklist, clean-VM install/upgrade/uninstall, real public CI/provenance, community compatibility reports and signing decision.

Later: additional presets, profile library, multiple virtual outputs, multiple instances of each semantic role, graphical per-mode override editor and profile auto-switching.

No gameplay automation, input replay, auto-aim, recoil control, game memory or anti-cheat bypass.
